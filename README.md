# DnDGen/.github

What the whole DnDGen organisation shares. Each repository's own README covers that repository;
this one covers what sits above them all.

| Folder | What it holds |
|---|---|
| [profile](profile/README.md) | The organisation's page at [github.com/DnDGen](https://github.com/DnDGen): what DnDGen is, and every repository in it |
| [theme-song](theme-song/README.md) | *Rogante Marendor*, the DnDGen main theme, with the soundtrack plan and how every repository gets a theme song of its own |
| [constitution](constitution/README.md) | The DnDGen constitution every repository is built by, and how a repository adopts it |

The main theme's lyrics come from the organisation's page, so a change to
[profile/README.md](profile/README.md) gets a song check: see the theme song's
[Remixing](theme-song/README.md#remixing) section.
